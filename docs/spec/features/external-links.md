# 外部リンクを新しいタブで開く

- 状態: Accepted
- 要件 ID の接頭辞: `LINK`
- 最終更新: 2026-10-19

## この機能が解決すること

メッセージの「参照URL」やマニュアルの PDF など、DUET の外のページへのリンクは、押すとツールバーもアドレスバーもない別ウィンドウで開きます。DUET が `openUrl` で `window.open` に画面の装飾を消す指定を付けているためです（E-036）。

さらに、これらのリンクの `href` は `?newwindow=true#` になっています。右クリックの「新しいタブで開く」や中クリックで開くと、参照先ではなく「今の DUET の画面の URL」を新しいタブで GET します。BetterDuet があれば着地ページに付け替えられて DUET のホームが開き、元のタブは古い画面になります。BetterDuet がなければ、セッションが壊れてすべてのタブがログアウトします（E-002、E-036）。

BetterDuet は、これらのリンクを普通のリンクに書き換え、どの開き方でも参照先が新しいタブで開くようにします。

## 利用者から見た動き

- **リンクを押す**：参照先が、同じウィンドウの新しいタブで開く
- **右クリックの「新しいタブで開く」、中クリック、Ctrl+クリック**：どれも参照先が新しいタブで開く。DUET の画面には何も送らない
- **リンクの上にマウスを置く**：ステータスバーに参照先の URL が出る

## 要件

### LINK-001 openUrl のリンクを普通のリンクにする

- 状態: Accepted
- 優先度: 必須

DUET の画面の `<a>` のうち、`onclick` が `return openUrl(…)` の形で、引数から開く URL を読み取れるものを、次のように書き換える。

- `href` を開く URL にする
- `target="_blank"`、`rel="noopener noreferrer"` にする
- `onclick` を外し、DUET の `openUrl` を動かさない

開く URL は、`onclick` の引数の形に応じて読み取る（E-036）。

| 引数の形 | 読み取る値 | 使われている画面 |
|---|---|---|
| `$('#ID').val()` | `id` が `ID` の要素の `value` | メッセージ詳細の「参照URL」 |
| `$('.CLASS').html()` | クラスが `CLASS` の最初の要素の文字 | マニュアル |
| `'…'`（文字列） | その文字列 | （未確認。書かれていれば対象にする） |

書き換えは画面の読み込みごとに1回だけ行い、何度走っても結果は変わらない。

受け入れ条件:
- メッセージ詳細で「参照URL」を押すと、参照先が同じウィンドウの新しいタブで開く
- 同じリンクを右クリックして「新しいタブで開く」を押すと、参照先が新しいタブで開き、DUET には何も送られない。元のタブの画面固有のボタン（「戻る」など）もそのまま使える
- マニュアルの画面で PDF のリンクを押すと、PDF が新しいタブで開く

### LINK-002 読み取れないリンクには手を加えない

- 状態: Accepted
- 優先度: 必須

次のどれかに当たるリンクは、書き換えずに DUET 本来の動き（別ウィンドウ）に任せる（P-5）。

- `onclick` が上の表のどの形にも当たらない
- 読み取った値が `http://` か `https://` で始まる正しい URL でない（DUET の `openUrl` も、この場合は開かない）
- 開く先が DUET 自身（`duet.doshisha.ac.jp`）。新しいタブで DUET の画面を GET すると、BetterDuet が着地ページに付け替えて元のタブが古くなるため

受け入れ条件:
- `tests/core.test.js` で、上の3つの場合に書き換えの対象にならないことを確かめる

## 今回は対象にしないこと

- **シラバス、得点分布、授業公開**：`openUrl` ではない関数で開き、得点分布と授業公開は POST で開く（E-018）。普通のリンクに書き換えられないため、CORE-007 のとおり今までどおり別ウィンドウで開く
- **添付ファイル**：`form1` の送信でダウンロードする（CORE-005）
