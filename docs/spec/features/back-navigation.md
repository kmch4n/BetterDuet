# ブラウザの「戻る」

- 状態: Accepted
- 要件 ID の接頭辞: `BACK`
- 最終更新: 2026-10-17

## この機能が解決すること

DUET では、ブラウザの「戻る」を押すと「ブラウザの『戻る』ボタンは利用できません」という警告が出て、何も起きません。BetterDuet は、「戻る」を押したらそのタブで1つ前に見ていた画面を開き直すようにします。

DUET は自分で `pushState` をしているため、「戻る」を押してもページは移らず、`popstate` が起きるだけです（E-017）。BetterDuet は DUET より先にこの `popstate` を受け取り、DUET の警告の代わりに、前の画面を開き直します。

## 利用者から見た動き

- ホーム → 成績確認 → お知らせ と進んだタブで「戻る」を押すと成績確認が、もう一度押すとホームが表示される
- 詳細画面から「戻る」を押すと、その一覧のメニュー画面が表示される
- 「進む」は使えない

## 要件

### BACK-001 DUET の「戻る」の警告を出さない

- 状態: Accepted
- 優先度: 必須

早期フックで、DUET の `popstate` の監視が登録されないようにする（E-017）。DUET が読み込み時に行う `pushState` はそのまま残す。これにより「戻る」を押してもページは移らず、`popstate` は拡張機能だけが受け取る。

受け入れ条件:
- DUET の画面で「戻る」を押しても、「ブラウザの『戻る』ボタンは利用できません」の警告が出ない

### BACK-002 「戻る」で1つ前の画面を開き直す

- 状態: Accepted
- 優先度: 必須

`popstate` を受け取ったら、すぐに `pushState` で履歴を1つ積み直し、次の「戻る」も受け取れるようにする。そのうえで、そのタブの画面の履歴（CORE-002）から、1つ前の画面を開き直す。

- 1つ前の画面がメニュー画面なら、その画面を開く
- 1つ前の画面が詳細画面なら、その詳細画面の戻り先のメニュー画面を開く。今の画面と同じメニュー画面になる場合は、さらにその前の画面を対象にする
- 開くときは、送信係を通して、最新の画面の型のフォームに、その画面を開くアクション（ホームなら `unloadform:goHome`）を入れて送信する。開いた画面は、履歴に新しく積まず、履歴の位置を1つ戻す
- 開いた結果、タブは最新のタブになる

「戻る」で開き直す送信も、ほかの送信と同じく CORE-003 の順番に従う。

受け入れ条件:
- ホーム → 成績確認 → お知らせ と進み、「戻る」を押すと成績確認が表示される。もう一度押すとホームが表示される
- 登録科目一覧 → 科目の詳細画面 と進み、「戻る」を押すと登録科目一覧が表示される
- ほかのタブで操作したあとの古いタブで「戻る」を押しても、どのタブもエラー画面にならない

### BACK-003 戻る先がないときは何もしない

- 状態: Accepted
- 優先度: 必須

そのタブの履歴に1つ前の画面がないときは、送信しない。NOTICE-BACK-1 の帯を出す。

受け入れ条件:
- SSO ポータルから開いた直後のホームで「戻る」を押すと、画面は移らず NOTICE-BACK-1 の帯が出る

### BACK-004 「戻る」のキー操作も使える

- 状態: Accepted
- 優先度: 推奨

DUET は Alt+← を無効にしている（[duet-platform.md](../duet-platform.md) の「画面側の制限」）。早期フックで、Alt+← が DUET の keydown の処理に届かないようにし、ブラウザの「戻る」として働かせる。マウスの「戻る」ボタンは DUET に止められていないため、そのまま BACK-002 になる。

Alt+→（進む）、Backspace、F5 などのほかのキーは変えない。

受け入れ条件:
- DUET の画面で Alt+← を押すと、BACK-002 と同じく1つ前の画面が表示される

## 既知の制限

ページを一度も操作していない状態で「戻る」を押したときの Chrome の挙動は確かめきれていない（E-026）。Chrome は、利用者の操作なしに追加された履歴を「戻る」で飛ばすことがあり、その場合は BACK-002 が働かず、前の DUET の画面（POST の結果）に戻ろうとする可能性がある。実装後に実機で確かめ、問題があればこの仕様を直す。

## 今回は対象にしないこと

- **「進む」**：「戻る」で開き直した画面の先へ進む操作。必要になったら、履歴の位置を進める形で追加できる
- **詳細画面への「戻る」**：詳細画面を開き直すには、そこまでの操作を順に送り直す必要があるため、今回は戻り先のメニュー画面で代える
