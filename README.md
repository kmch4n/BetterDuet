# BetterDuet

同志社大学の DUET を、もっと使いやすく。

DUET を複数のタブで開いても、再読み込みしても、ログアウトされないようにする Chrome 拡張機能です。最初の機能の実装が終わり、手元の Chrome で動作を確認した段階です。まだ配布していません。

> [!NOTE]
> 同志社大学および DUET の運営とは関係のない、個人による非公式の開発です。

## 開発の状況

仕様駆動開発で進めています。何を作るか、どう動くべきかは [仕様書](docs/spec/README.md) に、実装の仕組みは [技術ノート](docs/TechNote.md) に、テストと動作確認の手順は [開発と確認の手順](docs/DEVELOPMENT.md) にまとめています。

| 機能 | 状態 |
|---|---|
| 複数タブでの利用 | 実装済み |
| セッションの保護と復帰（再読み込みや休止したタブで壊れない、SSO を通らずに戻れる） | 実装済み |
| ブラウザの「戻る」 | 実装済み |
