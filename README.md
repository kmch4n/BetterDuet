# BetterDuet

同志社大学の DUET を、もっと使いやすく。

DUET を複数のタブで開いても、再読み込みしても、ログアウトされないようにする Chrome 拡張機能です。現在は仕様を固めている段階で、まだ配布していません。

> [!NOTE]
> 同志社大学および DUET の運営とは関係のない、個人による非公式の開発です。

## 開発の状況

仕様駆動開発で進めています。何を作るか、どう動くべきかは [仕様書](docs/spec/README.md) にまとめています。

| 機能 | 状態 |
|---|---|
| 複数タブでの利用 | 仕様の確認待ち |
| セッションの保護と復帰（再読み込みや休止したタブで壊れない、SSO を通らずに戻れる） | 仕様の確認待ち |
| ブラウザの「戻る」 | 仕様の確認待ち |
