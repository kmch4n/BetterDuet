# BetterDuet

同志社大学の DUET を、もっと使いやすく。

DUET を複数のタブで開いてもログアウトされないようにすることから始める、Chrome 拡張機能です。現在は仕様を固めている段階で、まだ配布していません。

> [!NOTE]
> 同志社大学および DUET の運営とは関係のない、個人による非公式の開発です。

## 開発の状況

仕様駆動開発で進めています。何を作るか、どう動くべきかは [仕様書](docs/spec/README.md) にまとめています。

| 機能 | 状態 |
|---|---|
| 複数タブでの利用 | 仕様の検討中 |
| ブラウザの「戻る」 | 候補 |
| ショートカットキーの復活 | 候補 |
